# Running Proton Platform

## Prerequisites
- Node.js (v18+ recommended)
- npm

## Setup
```bash
npm install
```

## Development
Start the local dev server (Vite, with hot reload):
```bash
npm run dev
```
Then open the URL shown in the terminal (typically http://localhost:5173).

## Build
Create a production build:
```bash
npm run build
```

## Preview production build
Serve the built output locally:
```bash
npm run preview
```

## Lint
```bash
npm run lint
```
